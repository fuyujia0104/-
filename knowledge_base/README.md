# 知识库

本目录包含城市感官探索家项目的文化知识库数据。

## 文件说明

知识库中的每个文件都是一个JSON格式的知识条目，包含以下字段：

- `id`: 唯一标识符
- `title`: 标题
- `content`: 内容
- `tags`: 标签列表
- `created_at`: 创建时间
- `updated_at`: 更新时间

## 添加新知识

您可以手动添加新的知识条目，只需创建一个新的JSON文件，并遵循以下格式：

```json
{
  "id": "unique_id",
  "title": "知识标题",
  "content": "知识内容",
  "tags": ["标签1", "标签2"],
  "created_at": "2024-01-01T00:00:00",
  "updated_at": "2024-01-01T00:00:00"
}
```

注意：
- `id`字段必须是唯一的
- `tags`字段是一个字符串数组
- 日期时间格式遵循ISO 8601标准

## 知识库用途

知识库用于为用户提供地点的文化背景和历史信息。当用户探索某个地点时，系统会根据位置和关键词从知识库中检索相关的文化信息，丰富用户的探索体验。
